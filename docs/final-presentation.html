A connected workflow

From a quick entry to a useful monthly view.

Transaction history

Newest-first records, edit/delete safeguards, search, category and date filters, sort controls, and filtered CSV export.

Categories and budgets

Private starter and custom categories, one monthly limit per category, and clear spent/remaining calculations.

Dashboard and comparison

Monthly income, expenses, net cash flow, category chart, budget warnings, and a two-month spending comparison.

Savings goals

Dated contribution records, clear progress toward a target, and a visible savings history.

Trust is part of the product

Your financial details stay within your account.

Secure sign-in

Email-based accounts, Django sessions, validated passwords and Argon2 password hashing.

Private records

Views and financial queries scope records to the signed-in user. Cross-account object requests return not found.

Careful exports

CSV is private and uncached, follows active filters, and neutralizes formula-leading descriptions.

Budget warnings inform the user without preventing a valid expense from being recorded. Recurring entries are anchored, idempotent and preserve history.

Built to be understandable

A small, testable Django foundation.

Application

Django 5.2 templates, a custom email user model, and owner-scoped domain logic.

Data

SQLite for local development; PostgreSQL is supported through DATABASE_URL for deployment.

Interface

Accessible responsive Bootstrap UI and a locally vendored Chart.js bundle, with no runtime CDN dependency.
